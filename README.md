# Track 2A Template

This repository is a clean starter template for the AI Testing Bootcamp Track 2A workflow.

Use it as a blank scaffold:
- Add one module at a time.
- Replace each placeholder README with your own notes and deliverables.
- Commit only the work you want to keep in the template repo.

## Structure

- `module-7a/` - Foundations, PromptFoo, and test strategy
- `module-7b/` - Assertions, cost evaluation, and prompt management
- `module-7c/` - Red teaming and vulnerability reporting
- `module-7d/` - Black-box testing, bug reports, and industry verticals
- `module-7e/` - Evaluation, RAG, and agentic testing
- `module-7f/` - CI/CD, observability, and resilience
- `capstone/` - Final end-to-end application test

## Start Here

1. Create your virtual environment if needed.
2. Add the files for the module you are working on.
3. Keep outputs and findings in the module folders instead of the root.
4. Update this README as the template evolves.
